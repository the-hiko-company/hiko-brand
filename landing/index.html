01 The Stack

Seven layers, one contract. Each layer speaks typed interfaces to the next; every seam is a plugin; nothing is a black box.

core Foundation

Interfaces, runtime primitives, and the Conductor — a DAG lifecycle orchestrator that brings the system up wave by wave and tears it down in reverse.

hal Platform

One abstraction over autopilots and sensors. PX4 today, Betaflight tomorrow, the next flight controller after that — the stack above never notices.

gnc Guidance · Nav · Control

Proportional navigation, L1, pursuit. An ESKF that shrugs off GNSS dropout. SE3 and cascaded control down to actuator allocation.

autonomy Decision

A custom behavior-tree engine, hierarchical state machines, task planning, and a mission manager that closes the sense–plan–track loop.

perception Vision

Detection, tracking, optical flow, and a VIO front-end — written on raw image buffers, tuned for embedded silicon.

fleet Multi-robot

Multi-agent pathfinding, consensus formation, hexagonal airspace cells, and an aerial order protocol for coordinating many vehicles at once.

data Memory

Automatic chunked recording, host-metrics logging, and a flight-data catalog: every simulation and every flight becomes a dataset by default.

rails Sim · GCS · Dashboard · Deploy

A SITL scenario harness, a ground control station, post-flight analysis, and one-command bringup ride alongside the stack from bench to field.

02 Principles

Four rules, no exceptions. They cost us speed on day one and repay it every day after.

Lifecycle-first

Every node is a managed lifecycle node, orchestrated as a dependency graph. Nothing starts by accident; nothing dies unnoticed.

Executor discipline

Explicit executors, deliberate callback groups, dedicated threads on hot paths. Concurrency is designed and documented — never inherited.

Implemented in-house

Controllers, estimators, planners, protocols — written here on a deliberately thin dependency base. If it flies, we can read every line.

Every run recorded

Recorder and syslogger sit in every graph, sim or flight. Data, host metrics, code version, parameters: reproducibility is the default.
